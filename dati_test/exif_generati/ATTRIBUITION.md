# Synthetic dataset

The files in `immagini/` are derived from the base image.

GPS coordinates, timestamps and other EXIF metadata are generated
artificially for functional tests of GeoEvidence Correlator.

Any metadata present in the original source image are not used as
forensic evidence and do not represent real-world events.
